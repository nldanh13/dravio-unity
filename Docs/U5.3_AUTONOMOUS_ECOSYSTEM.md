# U5.3 — Autonomous Ecosystem candidate

Integrates PR #40 / #41 / #42 on a new branch, preserving U5.2 and main. Schema v8, Rig v4.
- Presentation consumes BehaviorQueries.All per state revision/phase/deadline (not per render frame). Environment's actually applied phase is the single source for day phase; absent environment uses Day. Domain clock remains authoritative for canonical elapsed time.
- Ground presentation: decisions map to Rig v4 intents/personality; explore walks to safe authored positions, rest/bask/explore may reserve compatible ground points via EnvironmentInteractions (unique occupant per UID, release on change/removal/destroy). Cosmetic feedback only. Gameplay Rest stays in place, and waking dragons do not translate until Wake has finished. Missing medium or unsafe path is a reported fallback, not fake swim/fly/burrow.
- Player selection and pet trigger personality reactions; accepted food consumption drives Eat from the canonical timestamp. Manual doze is a 15-second visual override for ambient decisions only. No energy change.
- Feed default retains selected UID and first allowed diet from U5.2. Experimental sharedFoodAllocation inspector toggle (off) uses preferred diet and the Domain allocation (ADR 0203 A4/B7); the physical marker never teleports or changes ownership on selection. Only an eligible, live dragon within reach may consume. One local marker; restored/untracked food expires. A path blocked or a missing model can leave food unconsumed; no substitute species or free XP.
- Profile displays traits, preferences, phase, requested behavior, reason, last effective intent, point, fallback, ecology factor failures and clip substitution count. Research journal, Comfort drift, energy and natural disasters remain disabled. No new save or economy rules. Behavior weights and visual mappings are provisional.
- New scene OriginAutonomousEcosystem; import real Rig v4 catalog using run_u6_local.ps1 before Dravio > Open Game. Legacy FBX requirement and fallback retained. Do not overwrite approved assets or remove tracked controllers; back up local generated assets and save.
