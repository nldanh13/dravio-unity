# U6.0.2a — Safe local Alpha scene preparation and Android build
This patch intentionally disables SampleScene in tracked global settings rather than pretending the missing scenes exist. Prepare Connected Worlds validates Origin plus the two additive environments, enables exactly the three canonical scene entries, disables (never deletes) other entries, refuses to leave unsaved/untitled scenes. Existing scene files are not rebuilt. The Alpha APK menu uses an explicit scene list and scene role/missing-script checks, restores the previous scene setup, requires Android as active target, refuses AAB mode and existing output, and runs a Development APK build only when the owner explicitly invokes it. No APK built by remote CI.

## Local workflow
1. Preserve backup/local-unity-assets; use a separate test save and back up local scenes. Fetch the approved integration branch, do not reset local changes.
2. Unity 6000.6.10f1 with Android SDK/NDK/OpenJDK. Wait for compile/import and save any open untitled/dirty scenes manually.
3. If no Origin scene, install the refined Emberling FBX and environment assets required by existing generator. Existing procedural preview export: `powershell -ExecutionPolicy Bypass -File scripts/art/Export-EmberlingPreview.ps1 -Mode Refined` (Blender path may need -Blender); this is a preview, not production asset approval. Prefer verified real-source asset from AI3. Do not overwrite an existing FBX or scene. Environment generation may still need its mesh/material kits, see Environment README.
4. Dravio > Worlds > Prepare Connected Worlds. Check console. Open OriginLongTermGameplay. Active Build Profile can override global scene list; use the dedicated Alpha build menu for explicit scenes. Run scripts/qa/check_alpha_build.py again.
5. Switch Android Build Profile target, disable Build App Bundle, verify package identifier and SDK. Dravio > Alpha > Build Android Development APK. Choose new output under Builds (ignored by Git), never Assets. Do not install over a production save; this build retains the current template package identity.
6. Run A01-A11 from U5.9_ALPHA_ACCEPTANCE.md and record actual evidence.

## Scope / gaps
No fabricated Unity YAML scenes, no model imports, no app identity/SDK change, no save schema or Domain changes. Scene validation checks component counts and environment roles, not all serialized links or runtime behavior. Existing generated HUD may be stale; back up and migrate/regenerate separately if needed. Source preflight may still BLOCK until scene files exist locally. Unity Editor compile and build, Android install and device QA NOT RUN. Source CI excludes these Unity Editor APIs.
