## Player-facing flow
- New Log / Sổ tab in scrollable landscape HUD, three modes: Codex / Observe / Quests. English/Vietnamese headings, next/previous by stable ID. Some domain keys, enum labels and IDs remain untranslated. Dynamic text heights instead of a fixed-length list that clips long descriptions.
- Codex browser shows all canonical species slots (16), undiscovered slots masked, discovered species variants from Codex (64 total across species), life stages, observed behaviors/phases/habitats, research days, circadian coverage, progress and next hint. Details respect RevealedSections; current Codex gating stays OFF per ADR0205. Reading a page does not record a profile or mutate state. Existing profile-record controls remain separate.
- Observe shows actual current-world live projected residents from ObservationOpportunities, prioritization from Domain (worthwhile first), availability, cooldown, potential findings, daily cap deferrals and individual records. Selection is by UID, not moving list index. The existing ObserveDragonCommand is sent only after re-reading live opportunities for the chosen UID, current canonical zone and current environment phase. Existing roster research action uses the same guard. No automatic recording on opening or browsing. Accepted or rejected result reflects actual session. Domain controls all cooldown and recording semantics.
- Quest mode displays requirements, locks, progress, canonical gate vs proposal, completion rule flag. No completion button, no reward claim, no unlock bypass. U2.11 remains pending.
- Session feedback listens for DragonObserved and NightJournalWritten, does not fabricate an event history. Persisted aggregate species/individual research is visible after reload, but source/timestamp of individual historical findings cannot be reconstructed from v9. Startup offline journal event may predate subscription; do not label aggregate findings as night-specific. No new persistence.
- Refresh only when page visible, on state reference/language/event changes or ~0.75s interval; current prototype computes overview and opportunities on demand. Real mobile layout and CPU still need QA.
