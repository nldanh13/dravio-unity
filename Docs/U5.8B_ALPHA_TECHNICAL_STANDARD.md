This document is shared across AI1/2/3; do not interpret suggested targets as external mandates or measured results.

## External guidance
- Unity 6 optimization guides: https://unity.com/blog/unity-6-game-optimization-guides — profile target hardware, not just Editor.
- Unity URP: https://docs.unity.cn/Manual/urp/understand-performance.html — measure render passes, copies, draw submissions and GPU costs; avoid unnecessary textures.
- Android power: https://developer.android.com/games/optimize/power — common 30/60 FPS targets, frame pacing and thermal management.
- Unity frame pacing API: https://docs.unity3d.com/6000.0/ScriptReference/PlayerSettings.Android-optimizedFramePacing.html
- Android accessibility: https://developer.android.com/guide/topics/ui/accessibility/views/apps-views — 48 x 48 dp recommended touch area (not Canvas units).
- Xbox Accessibility Guideline 102: https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/102 — 4.5:1 contrast for important normal-size text.
- Google Play target API: https://developer.android.com/google/play/requirements/target-sdk — from 2026-08-31 ordinary new apps/updates target API 36+; separate from local APK compatibility. Recheck before release.
- Android memory: https://developer.android.com/games/engines/unity/unity-reduce-memory — use target texture compression and measure memory/LMK.
- Android slow sessions: https://developer.android.com/topic/performance/issues/slow-session — real presentation intervals, not Unity average FPS alone.

## Candidate device gates (DRAVIO targets, not industry limits)
- Baseline 30 FPS, frame period ~33.33 ms; short-screen avg >=29, 1% low >=24. Optional future 60 FPS mode period ~16.67 ms, avg >=58, 1% low >=48; test display cadence. No 60 mode activated.
- Test physical Android 4 GB and 6–8 GB RAM reference tiers; actual device names/GPU/OS to be selected by owner. Tier is a workload category, not minimum supported RAM. Record build SHA, renderer/API, resolution, refresh, quality, scene, power state, device temperature/thermal status when available.
- Run 5/15/30 dragon stress report with >=30 s warmup and >=60 s sample per count; default harness (3/10 s) is smoke only. Require at least half requested visible on average for comparable screen; verify actual spawns separately. Initial soft review thresholds (draw calls / SetPass / triangles, entire stress scene): 5 = 150/80/200k; 15 = 250/120/350k; 30 = 350/160/500k. These are hypotheses; use CPU/GPU profile to tune. Do not count them as requirements for individual meshes.
- Run actual connected world gameplay for >=20 min on each reference tier (Origin/Ocean/Sky as unlocked, day/night, UI, feeding, breeding, expedition, construction, visit and reload). Record p50/p95/p99 frame time, 1% low, CPU/GPU separately, GC allocations, memory peaks and PSS via Android tooling, draw/SetPass, dropped frames, thermal throttling, crash/ANR. Suggested investigation triggers: p95 > 40 ms at 30 FPS, p95 > 20 ms at 60; memory PSS >600 MiB on 4 GB or >900 MiB on 6–8 GB (provisional, not platform thresholds); sustained memory growth after three world loops >10% above post-warmup baseline. Require no crash/ANR, no lost or duplicated transactions. Measure release build separately; development counters may differ. Do not claim certification from a short harness.
- Touch area >=48dp measured on physical device; current 44–48 Canvas units not proof of dp. Normal important text contrast >=4.5:1, no color-only state, no clipped VI/EN text, safe-area landscape in both orientations. Test scroll and all controls. Text size proposals: body 15–16 reference Canvas units, heading 18–20, verify readability on phone; not physical dp.
