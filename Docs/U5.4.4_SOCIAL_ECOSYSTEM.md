## Integration
- Experimental Social Presentation Inspector toggle on LivingSanctuaryPresentation, Editor only, default OFF. No active social projection in player build.
- Existing ProgressionQueries.SocialInteractionCandidates is the sole matching authority. Candidate must be presentation-only, same current zone/habitat, still current/eligible, both live ground residents with PASS rig clip map and exact-stage or Unstaged model. No pair for actual sleep, gameplay Rest, feed/eat, manual doze, or non-ground residents. One global active lease per controller, at most one started pair per participant per 60s canonical epoch, no reset by scene visit, max 12s lease and up to 2.5s interaction window. Time rollback, expiry, replaced candidate, move/storage/stage/variant changes, food or player pet/doze cancel. Existing gameplay behavior remains higher priority.
- CuriousApproach: initiator approaches stationary partner, then faces and requests existing Greet; partner faces and shows Idle. PlayTogether: same approach/face, then both request Play (existing Happy one-shot). RestTogether: both request existing Rest; actual Sleep is excluded, no forced wake. KeepDistance is not implemented as active retreat: ignore candidate, retain canonical individual behavior. All effects cosmetic, no GameSession.Send in scheduler, no relationship gains or persisted affinity, no XP/health/bond/gold rewards.
- Use existing authored ground spawn endpoints only; if already within range and geometry segment clear, stay. Do not move partner or invent destination. Respect max(.55m, candidate personal distance), endpoint buffer .12m when approaching, interaction range up to min+.8m. Same ground route budget, sampled dynamic separation along steps, no mesh collision certification. No shared point use while paired. On lease completion/cancellation release both routes/reservations; noninterruptible animation already started can finish under Character planner. This is a paired intent window, not exact simultaneous animation-event synchronization.
- Profile shows candidate and active phase/last result. A/B trial only; no default gameplay change. Limitations: one global pair can starve other pairs under high density; fixed authored endpoints can be sparse; no active space-seeking, actual body-size correction, water/air social behavior or family-specific clips yet. Candidate API recomputes behavior and social relations on decision cadence; profile and CPU need local review.
