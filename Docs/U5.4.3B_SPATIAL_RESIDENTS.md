## What is implemented

LivingSanctuaryPresentation now has an opt-in Editor-only Experimental Spatial Residents setting, default OFF, sampled at world bind (leave/revisit to change). On the existing Connected Worlds scene, visit an unlocked Ocean/Sky after enabling it in the Inspector. The actual GameSession resident UID is projected into its canonical habitat, not a temporary synthetic dragon. Ocean swim-capable species and Sky fly-capable species request their realm medium. Origin is unchanged. No cross-medium animation or transfer is inferred: direct placement at an authored same-medium spawn represents reloading an already resident dragon, not takeoff or water entry. Do not call it a certified transition.

Requires a same-species exact or Unstaged rigged catalog entry (never OtherStage), PASS animation QA, explicit Swim/Fly clip and speed, valid Rig v6 body/medium dimensions and turn rate, unit prefab root scale, authored volume, safe spawn. Unapproved models are permitted only in this explicit Editor review; profile retains approval label. Missing metadata/space means unavailable, not a different species or reduced clearance. Actual live instance/clip checked after Sync before movement; mismatch quarantines UID until next world bind. Growth/stage/variant change reprojects at a valid spawn. No save or canonical UID change.

3D paths use SpatialMediumReview (768 expanded nodes, shared one route search per rendered frame, dense .025m recheck). Select authored endpoints in ID order, try subsequent endpoints on failure, no invented goals. Signed yaw, vertical speed and actual translation speed feed existing Rig v6 shaper. Only presentation Explore/Play/Swim/Fly decisions translate; other decisions hold root. This uses SanctuaryDragonSync's explicit locomotion path (intent None), not its Ground-starting transition planner, so no root-offset application or transition status is claimed. Swim/Fly loops can continue in place while stopped; this is not physically correct hover/respiration/rest. Feeding, pet and doze disabled for spatial resident; care management/storage/move and existing observation queries remain canonical.

Mixed ground/spatial separation uses horizontal circles ignoring height (spatial envelope radius + ground .275m proxy); conservative but can reduce density. Dynamic checks against current positions are sequential, not continuous multi-body swept mesh collision. Ground steps in enabled view additionally sample separation along path. Geometry envelope is root-centred proxy from catalog extents, not certified actual pivot-relative body or animation bounds. No artificial deep water, flight volume, burrow, perching, landing or cross-floor paths added.
