# U6.1 — Player journey: one "next step" across all systems

Base: `feat/u5-6-player-journey` 9db80f1. Presentation only: no Domain rule, save schema, balance, scene or asset change.

## Problem
Every system already runs on the one `GameSession` of `OriginLongTermGameplay` (care, biology, roster/travel, tutorial guide, eggs/breeding, management: worlds, projects, upgrades, expeditions, health; research/quests). But the player sees seven tabs of buttons and no answer to "what do I do now?". The Domain already knows the answer (`Tutorial.CurrentStep`, `JourneyGuide`, claims), yet the journey text sat at the bottom of Log › Quests.

## Change
- `Scripts/PlayerJourneyPlanner.cs` (pure C#, dotnet-tested): merges the canonical answers into one prioritized prompt with chapter, title, hint and the drawer page that holds the button.
  Priority: disaster shelter → care case action → waiting rewards (egg, bred egg, expedition) → tutorial step → JourneyGuide step to the next world → ready side quest → main loop (expedition, sanctuary project, breeding, care).
  Chapters: 1 Origin tutorial · 2 road to Ocean · 3 road to Sky · 4 main sanctuary loop.
- `Scripts/JourneyBanner.cs`: card at the top-left of the HUD (under the header, left of the drawer) with chapter, next step, hint and **Đi tới ›** which opens that page (Log opens in Quests or Observe mode). Milestone toasts for tutorial steps, habitats, worlds, quests and returning expeditions. A skipped tutorial gets a one-tap **Tiếp tục** (plain `SetTutorialStatus(Active)`), the only command the banner sends.
  Installed at runtime after the first scene loads when exactly one `DravioSessionHost` and one 7-page `FantasyPreviewUI` exist, so the committed scene needs no regeneration.
- `FantasyPreviewUI.SelectPage/SafeRoot/PageCount` and `ResearchDiscoveryPanel.ShowMode` expose existing behaviour to the banner.

## Tests (source only)
`Tests/Integration~/PlayerJourneyPlannerTests.cs`: a bot that follows only the banner (page + the button its hint names) carries a fresh save through all eight tutorial steps into chapter 2 (first Ocean step: research observations for "Ghi chép Khởi Nguyên"); rewards outrank tutorial; skipped tutorial resume; 30 offline hours always produce a prompt; milestone toasts. Full integration suite 179/179 locally. `JourneyBanner` type-checked against UnityEngine 2021.3 reference modules plus uGUI signature stubs; not compiled in Unity 6.
