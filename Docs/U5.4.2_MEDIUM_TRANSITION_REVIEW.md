## Implemented

- MediumReviewEnvelope derives horizontal circumscribed radius and vertical half extent from Rig v5 body/medium dimensions + 0.10m review margin. Missing, zero, negative or non-finite dimensions fail. These are centred root proxies, not true root-relative animated mesh bounds; do not use as production collision certification.
- SanctuaryNavigationSurface.ClearReviewVolume keeps separate horizontal and vertical margins inside an existing authored same-habitat swim/fly volume and checks obstacle data at the lower extent. Existing production ground clearance unchanged.
- SpatialMediumReview uses the existing bounded 3D A* (2048 node default) and dense 0.025m segment validation. No route if endpoints/edges fail.
- MediumTransitionGate is a pure one-UID transition contract prototype. Explicit certificate ID, canonical eligibility, approved exact model, authored clip, readiness, source/target clearance and independently reviewed corridor are mandatory inputs. It does not generate a certificate or know actual GameState. Hold translation while expected clip plays; apply TakeOff offset only on completion and Land offset only on first active frame. WaterEnter/Exit require an explicit shared endpoint and no invented offset. Verify clip observed, proper completion, exact target, matching UID/zone/habitat/model and monotonic Sync tick. Fail locked on invalid offset, missing/interrupted clip, stale Sync, lost eligibility or changed clearance. Do not teleport rollback after any fault. Caller must implement actual certificate lifecycle, exclusive reservations, timeout, quarantine and post-Sync position application. Not wired to live controller yet.
- Ten NUnit cases including missing evidence, expected transitions, missing clip completion, interrupt, duplicate sync, root offset, missing dimensions and 3D routes. Integration csproj includes pure review classes.
