# U5.3.6 — Multi-medium World navigation candidate

Base `feat/u5-autonomous-ecosystem@8352b6df`; previous branch and main unchanged.
This is a geometry/navigation integration, not new Domain rules or a finished playable Ocean/Sky.

## Shipped in this branch
- Pure deterministic bounded A* (`SanctuaryRoutePlanner`) with cardinal grid neighbors (0.45 m), direct-path fast path, checked shortcut smoothing and exact goal. Ground search cannot change height. Swim and Air use 3-D neighbors. All tested edges sampled at <= 0.1 m; invalid/blocked/unreachable/budget-exhausted paths fail closed, no partial path. Burrow deliberately unsupported.
- `SanctuaryNavigationSurface` reads existing generated location data. Ground validates same habitat, obstacle/water clearance and actual floor height. Swim/Air require explicitly authored 3-D volumes, vertical/horizontal margin (default 0.25 m) and obstacle checks. Origin pond only has a 2-D footprint; no invented depth or fake flight. Different floor heights and seabed movement are not traversed.
- Existing Origin resident controller caches routes to food, exploration and reserved interaction points; plans at most one search/frame (768 expanded nodes default); checks each local step and nearby dragon center separation (0.55 m), stops and retries on a moving obstacle, temporarily avoids failed targets. Route counters, selected route state and cyan editor gizmos. Gameplay rest/awake gates and canonical consume checks remain.
- `Dravio > Environment > Validate Navigation Routes` audits actual committed Origin/Ocean/Sky JSON and prints same-medium safe spawn and pair reachability counts. It creates temporary ScriptableObjects only, no scene writes, no state changes.
- Pure tests: direct, ground detour/smoothing, closed wall, spatial detours for Swim/Air, invalid endpoints, unsupported Burrow, budget bound, segment interior. Existing CI step compiles the planner in the Integration project.
- New generated scene `OriginMultiMediumWorld.unity`. Existing legacy FBX/catalog requirements remain; shared generated assets and save directory need backups.

## Safety boundaries and next integration
- Same-habitat, same-medium routing only. No cross-habitat auto walking or WorldGraph bypass. Existing explicit MoveDragon command retains authoritative eligibility; visual reposition is not an animated gateway crossing.
- Air/Swim planner is available for explicit authored volume tests; live residents still ground-only. No takeoff, landing, water entry/exit, underwater sleep, burrow or live zone switching until CHAR.7 motion readiness contract and safe transition metadata exist. Zone builders remain separate.
- Grid resolution, sampled geometry and fixed center separation are conservative approximations, not full mesh collision or certified body clearance. No guarantee of finding narrow routes, no rigidbody/navmesh avoidance, no guaranteed frame budget. Profile Unity on target hardware; tune only with measured clearance.
- Keep ADR 0202/0203 disabled gameplay rules, Schema v8 and Character Runtime unchanged. No rewards or save state from routing.
