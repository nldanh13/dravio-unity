## Read-only preflight
From repo root: `python scripts/qa/check_alpha_build.py`. Exit 1 BLOCKED, 0 SOURCE_READY. --distribution also flags template package/automatic target SDK as blockers. --report-only emits JSON without failing CI for expected local-generation gaps. Script checks exact policy scene paths, file presence/non-LFS pointer, global enabled order and .meta GUID, Android frame pacing/ARM64/IL2CPP, packages. It does not inspect active Build Profile overrides, compile Unity, confirm imported asset quality, or build APK. CI uploads snapshot; a green tool workflow is not a green build.
