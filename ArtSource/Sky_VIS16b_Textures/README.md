# VIS.16b — Sky meadow and cloud alternatives

Same dimensions as authored Sky ground (512²), cloud sea (256²), cloud wisp (128²). Ground soft meadow color fields, fine directional brush; cloud sea layered periodic color fields, not extra geometry or real volumetric cloud. White RGB straight-alpha wisp, transparent edge, keep existing particles (10 authored max). The existing Painterly Water shader reads RGB only, scrolls two samples with _ScrollA (.006,.002), _ScrollB (-.004,.003), UV second scale 1.37; keep existing material, tint, opacity and scroll. CPU approximation of linear RGB modulation is recorded in manifest (does not model lighting/fog/foam/wind). Ground and cloud repeat, wisp clamp; preserve .meta GUID, sRGB and alpha policy. Replace one-to-one only after review; no duplicate runtime imports. No added texture allocation if same import dimensions, no additional light, shader, material, renderer or particle controller. Sky budget stays 60k triangles, 10 materials, 6 MiB estimated RGBA32+mips. No gameplay changes, no changes to island colliders, spawn/perch/flight. Reproduce `node scripts/art/environment/build_sky_vis16b_textures.mjs <new-dir>`. Internal tests only; external decoding, Blender, Unity, Android and actual appearance NOT RUN.
