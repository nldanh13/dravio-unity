Check transparent sorting, depth test, overdraw, morph export/import and culling. No particle count, shader or runtime edits. Internal geometric/morph checks and deterministic bytes, no external validation or render. Reproduce `node scripts/art/environment/build_sky_vis16e_air_ribbons.mjs <new-dir>`.
