# VIS.16d — Sky decorative architecture

Two original GLB models: an ivory/gold astral lantern with a faceted blue crystal and an ivory/gold celestial halo monument with raised four-point star. Both grounded Y=0, front -Z, one shared source vertex-color material, explicit alpha zero and neutral UV0. Gold is painted color, not a metal or emission map; lantern has no actual light. Each closed component was checked for oriented paired position edges and positive signed volume, but assembly primitives intersect/touch and are not boolean unioned. Exact attribute tuple indexing preserves normals/colors. No texture. 1632 triangles if one of each. Optional cosmetic dressing only; never replace Sky Gate, Shrine, Bridge, Spire Perch or island surfaces. No new perches, collectible or interaction. Use existing approved static white-base material only if compatible with budget; preserve color, UV and alpha on FBX. No collider, flight, scene or gameplay changes. Require actual terrain and flight clearance, camera visibility, Blender/Unity visual and external validation. No render or device test here. Reproduce `node scripts/art/environment/build_sky_vis16d_architecture.mjs <new-dir>`.
