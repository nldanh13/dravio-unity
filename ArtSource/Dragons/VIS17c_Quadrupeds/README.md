# VIS.17c — Quadruped masked bake workflow

Seven species: Emberling, Droplet, Sprout, Magma, Mossback, Amberhorn, Gaia. No actual dragon texture authored in this step. Source GLB SHA256/length and embedded BaseColor hash gates, real UV inventory. Use VIS17 UV guide on a checkout; hand-paint full-size L PNG masks and manually project the VIS17b tonal studies into each chart (gray 128 neutral, range 84–172). Protect eyes, markings, genetics-sensitive regions, seams and chart gutters with a separate L PNG. No region may overlap protected pixels; soft region weights sum <=255. Review template intentionally invalid until a real reviewer supplies hashes and declaration. File paths constrained to review directory. Mask/tone PNGs must be 2048 square L mode. Original alpha and all unmasked/transparent pixels stay byte-identical after decoding. Multiply in linear RGB, reject new clipping, enforce per-study strength cap, roundtrip output PNG. No automatic UV inference, recoloring, normal map, material or rig edits. 

Node 18+ and Python 3 + Pillow required. `node scripts/art/character/dragon_vis17c_masked_bake.mjs --self-test` or `node scripts/art/character/dragon_vis17c_masked_bake.mjs <source.glb> <review.json> <new-dir-outside-Assets>`. 12 synthetic core checks executed; full CLI and actual UV/masks/GLB/FBX not run here. Review declaration is not independent verification. Compare FBX UV correspondence and actual render before importing, require repaired rig and all-frame QA for remaining 6. No runtime promotion. Original source and runtime untouched.
