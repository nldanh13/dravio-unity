# VIS.4a — Origin color texture candidates (Issue #90)
Seven original 512x512 repeatable color textures: packed earth, bark, warm sandstone, cool stone, canopy, red fruit and meadow. Broad softly shaded shapes, restrained detail, warm highlights and greener foliage; the style goal is bright cute fantasy. These are deterministic procedural art candidates, not hand-painted or visually approved production masters. Indexed 8-bit RGB palette, sRGB, opaque, no normal/roughness/emission maps. Dithering and hue bins may be visible at close range; judge at mobile camera distance.
## Atlas contract (existing atlas.py)
The 1024x1024, 4x4 prop atlas is NOT replaced. Proposed source mapping: stone_warm tile 0; stone_cool tile 1; bark tile 4; leaf_canopy tile 6; earth tile 12. Optional root tile 5 derivative. Preserve tile order, 12px UV inset, emission map, GUIDs, and unmodified tiles. Meadow is an independent ground map candidate. Red fruit has no current dedicated tile: do not replace mushroom_cap or reassign UVs automatically. Coordinate with the staged tree generator/AI #91 for a dedicated allocation. Texture candidates are 512x512 source; downsample to existing atlas cell resolution with padding/mip checks rather than import seven extra runtime textures. All colors authored as albedo, not baked lighting. Validate compression and 6 MiB existing budget.
## QA and reproduction
Run node scripts/art/environment/build_origin_vis4_textures.mjs <new-directory>. No dependencies. Every PNG was generated and the stored-deflate scanlines decoded in the generator and checked against original pixels/palette. Periodic function sampled at 64 points with translation +1 in U/V; edge mean RGB deltas recorded. This verifies periodic mathematical pattern, not a promise of invisible mip seams. Preview is a direct texture swatch board, not a Unity render. No changes in Assets, shader, scene, gameplay or existing art. External image decoder, Unity, Blender and performance checks not run.
