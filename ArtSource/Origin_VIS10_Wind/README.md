# VIS.10 — Wind-weighted flora

Original VIS8 bloom/fern shape and RGB retained, explicit COLOR_0 VEC4 alpha = height-based wind weight (root zero, upper foliage rises smoothly), constant UV0 for white base. Fungi remain static. Replace, not add to, VIS8 candidates. No new textures or triangles. Shader `Dravio/Environment/Painterly Lit` already bends positions in forward, shadow and depth passes. Recommend a shared dedicated opaque flora material with _BaseMap white, _VertexAO 1, _PathBlend 0, _WindStrength 0.012, _WindSpeed 1.6, _AlphaClip 0; never share with static architecture if its wind must stay off. Preserve RGBA on FBX conversion (do not zero alpha as for architecture); test seam preservation, bounds padding and actual scale. Existing EnvironmentWind drives global direction and gust; no new controller. One extra material only if accepted and within zone budget. No change to existing shader, geometry source, gameplay or scene.

Reproduce with Node 18+ `node scripts/art/environment/build_origin_vis10_wind_flora.mjs <new-dir>`. 216 sampled poses per mesh from baseline shader equation (base 0.5/1/2.2; gust 0/1; 3 directions; 12 phase times). Verified fixed zero-weight vertices, coincident weight equality, face angle and area ratio limits and max displacement, deterministic output. No runtime shader execution or visual render. Source GLB standard renderer does not show wind; alpha only used as wind in Dravio shader. Blender, external validator, Unity/Android NOT RUN; test actual transform scales and culling before import. No claim of production acceptance.
