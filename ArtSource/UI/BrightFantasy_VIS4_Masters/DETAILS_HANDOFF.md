# VIS.4 UI detail candidates
Six additional role sprites: frame/fill/highlight, portrait, divider and tab indicator. Source sizes/names/borders from #88 contract. Portrait aperture radius 164 px checked zero alpha. Progress frame has opaque recessed track (not a hollow overlay); draw fill on top, then optional highlight clipped to same value. Current DravioProgressBar.SetValue01 changes only fill or mask; it does not explicitly set highlight.fillAmount. Integration AI must put highlight inside mask or clip it separately; disable highlight if not synchronized. Filled mode clips right cap, Masked mode also clips full-size art at mask edge; neither automatically restores a rounded moving end cap. Preview demonstrates clipping, not actual Unity sizing. Progress fill default green; alternate colors may need neutral source/tint variants. Divider uses L/R 160px border, zero top/bottom. Portrait is Simple, not sliced. Test border compression at small bars and slots; 20u frame / 10u border each can leave zero vertical center. These are original raster procedural candidates, no baked labels, no runtime changes. PNG roundtrip, alpha counts and horizontal slice endpoint checks run; Unity, compression, visual sizing, external QA not run. Preserve old sources and import only reviewed files.
